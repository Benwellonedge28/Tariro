# Tariro IDE Bridge

This repository contains the Tariro IDE Bridge, an application that facilitates deep integration between the Tariro AGI and various Integrated Development Environments (IDEs) like VS Code, JetBrains products, etc.

The IDE Bridge acts as a local agent, enabling bidirectional communication with Tariro AGI for tasks such as:

*   **File Management:** Reading, writing, and listing files within the developer's workspace.
*   **Command Execution:** Running terminal commands directly within the IDE's context.
*   **Language Server Protocol (LSP) Integration:** Providing advanced language features (e.g., autocompletion, diagnostics, go-to-definition) for languages defined or generated by Tariro's Meta-Compiler.
*   **Settings Synchronization:** Managing IDE-specific settings and preferences.

## Key Components:

*   **IDE Integration (`ide_integration.rs`):** Defines the protocol and mechanisms for Tariro AGI to send requests to and receive responses from the IDE.
*   **Compiler Server (`compiler_server.rs`):** Implements an LSP server, allowing the IDE to understand and provide rich editing experiences for AI-generated or AI-managed code.
*   **Bridge Protocol (`bridge_protocol.rs`):** Establishes the communication format (JSON-RPC over standard I/O or WebSockets) between the AGI and the IDE Bridge.
*   **Handlers (`handlers.rs`):** Processes incoming IDE requests and dispatches them to the appropriate local filesystem or IDE interaction functions.
*   **Utilities (`utils.rs`):** Provides common helper functions for file system operations, path manipulation, etc.
*   **Error Handling (`error.rs`):** Defines custom error types for robust error management.

## Building and Running:

To build and run the Tariro IDE Bridge:

```bash
# Build the project (from Tariro root)
cargo build -p tariro_ide_idpte --release

# Run the IDE Bridge
./target/release/tariro_ide_idpte --port 5000
```

_Note: This bridge application is typically launched and managed by an IDE extension, which handles the communication channel setup (e.g., spawning this process and redirecting its standard I/O)._
